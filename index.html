      Getting the events onto your calendar

      Save .ics file saves the batch to Files. Open it from there and add the events — this is the route to use on iPhone.

      Share instead passes the same file to the share sheet, for sending the list to someone else or opening it in another app.

      The file holds every event in the preview. Saving again after an edit makes a fresh file rather than changing the old one.

      What it understands
      • 2026-09-03, 10/26, 3.9.2026, Sep 3, 3 September 2026
      • 9am, 9:30, 14:00-15:30, 9-5, noon
      • Oct 26,27,28 or 10/26,27,28 — one event per day, same month
      • Oct 26 & 27, 26, 27 and 28 Oct work too
      • Oct 2-5 or Dec 28 - Jan 3 — a dash means one event across those days
      • No year written means this year, or next year if the date has passed
      • all day anywhere in the line
      • @ place for a location, // text for notes
      • Tab or comma separated columns pasted from a spreadsheet
      • Lines starting with # are ignored
